# AWS Cloud Security Analysis Project

This project focuses on analyzing cloud security threats and implementing risk mitigation strategies using AWS cloud services.

## AWS Services Used
- Amazon S3
- AWS IAM
- AWS CloudTrail
- Amazon GuardDuty
- AWS Config

## Features
- Security threat analysis
- IAM access control
- MFA authentication
- Cloud monitoring
- Threat detection
- Security testing

## Project Type
MCA Final Year Project
